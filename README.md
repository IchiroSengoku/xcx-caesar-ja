# xcx-caesar-ja（シーザー暗号 拡張）

Xcratch（Scratch拡張環境）で使える **シーザー暗号（文字ずらし）** の拡張です。  
**ひらがな・カタカナ・英字・数字・漢字（Unicode範囲）** を対象に、指定した数だけ文字を循環シフトします。

---

## できること

- **暗号化**：`[TEXT] を [SHIFT] 文字ずらす`
- **復号**：`[TEXT] を [SHIFT] 文字もどす`

---

## 使い方（Xcratchに読み込む）

1. Xcratch を開く  
2. 「拡張機能を追加」→「Extension Loader」を選ぶ  
3. 下のURLを貼り付けて読み込む  

### 読み込みURL（配布用）

https://ichirosengoku.github.io/xcx-caesar-ja/caesarja.mjs?v=1

> **重要（更新時のコツ）**  
> 変更が反映されない場合は、URL末尾の `v=1` を `v=2`, `v=3` … のように増やしてください。  
> （ブラウザのキャッシュを避けるためです）

---

## 動作例

- TEXT：`あいうえお`、SHIFT：`3` → `えおかきく`
- TEXT：`ABCxyz`、SHIFT：`3` → `DEFabc`
- TEXT：`0129`、SHIFT：`3` → `3452`

---

## 仕様・注意

- ひらがな／カタカナは、拡張内で定義した文字表の範囲で循環シフトします。  
- 漢字は「Unicodeのコードポイント範囲（CJK統合漢字 U+4E00〜U+9FFF）」内で循環シフトします。  
  そのため、ずらした結果が別の漢字になり、意味は保持されません（教材としては「文字コードと変換」の理解に向きます）。  
- 句読点・スペース・記号など、対象外の文字はそのまま出力します。
