# xcx-caesar-ja（**シーザー暗号** 拡張）

Xcratch（Scratch拡張環境）で使える **シーザー暗号（文字ずらし）** の拡張です。  
**ひらがな・カタカナ・英字・数字・漢字（Unicode範囲）** を対象に、指定した数だけ文字を循環シフトします。

---

## ✅ できること

- **暗号化**：`[TEXT] を [SHIFT] 文字ずらす`
- **復号**：`[TEXT] を [SHIFT] 文字もどす`

---

## 🚀 使い方（Xcratchに読み込む）

1. Xcratch を開く  
2. **「拡張機能を追加」→「Extension Loader」** を選ぶ  
3. 下のURLを貼り付けて読み込む

### 🔗 読み込みURL（配布用）
